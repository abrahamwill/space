# Space house in Blender: read this first

`house_P2.glb` **is** the house. It is exported straight from the design's own 3D scene: the same triangles, colours and camera that made the hero image. Do not model the house or the furniture again. Open this file and work on top of it.

## 1. Open it
In Blender (4.x), run `setup_house_in_blender.py`, either from the Scripting tab or through the Blender MCP's execute-Python tool. Keep `house_P2.glb` in the same folder; if the script can't find it, set `GLB` at the top to its full path.

The script:
- imports the house
- makes **HeroCamera** the active camera: orthographic, azimuth 45°, elevation 30°, 1720 × 1320
- adds a sun matching the design's light, plus soft grey ambient
- sets colour management to **Standard**, so the hex colours render as designed (Filmic and AgX wash them out)
- turns `page_surface` into a holdout, so it hides everything below page level like the website's rim but renders transparent

## 2. Check it before changing anything
Render from HeroCamera with F12 and compare it with `reference/hero_P2.png`:
- the framing, every object and the colours should match
- lighting will differ slightly

If it doesn't match, fix the import settings. Do not remodel anything.

## 3. What's in the file
- **Units:** metres. **Up axis:** Z (Blender converts the glTF on import).
- **Objects:** 52, named `room_kind_label`. Examples:
  - `living_sofaL_Sofa`, `living_arclamp_Arc_lamp`, `living_ctable`
  - `studio_desk_Desk`, `studio_bookcase_Books`
  - `bedroom_desk_Desk___PC`, `lab_plinth_Laptop`
  - `deckS_treadmill_Treadmill`, `character_abraham`
  - `house_shell` (floors, walls, glass frames, stair), `wall_art` (every framed print and poster), `page_surface`
- **Materials:** one per flat colour, named by hex (`#6f8a3a` = sofa green). Materials named `glow_…` are light sources: lamp shades, screens, the PC's fans.
- **Shading:** flat-shaded, double-sided faces. Each object's origin sits at its own centre.

## 4. Allowed improvements (keep the design, add finish)
- **Bevel:** add a Bevel modifier of about 0.5–1 cm, 2 segments, with "Harden Normals" to soften box edges. Skip it on `wall_art`, `page_surface` and screens.
- **Lights:** light the `glow_` materials as real lights, for example a point light inside each lamp shade, at low strength.
- **Fabric:** add subtle texture only where the design names a fabric:
  - the sofa: bouclé
  - the orange chair: corduroy
  - the rugs: wool
  Keep the same base colours.
- **Shading:** add Ambient Occlusion (EEVEE) or render in Cycles, with soft sun shadows.

## 5. Not allowed without asking Abraham
- Moving, resizing, adding or removing objects.
- Changing any colour, or the camera.
- Remodelling a piece "to look better". If something looks wrong, list it and ask.

## 6. Export for the website (milestone 2, live 3D)
`File > Export > glTF 2.0 (.glb)`:
- Turn on **Apply Modifiers**, **Draco** compression and **+Y up**.
- Leave out `HeroCamera` and `Sun` if three.js sets up its own camera and light.
- Keep the object names: the site uses them for hotspots and click-to-task.

## 7. Source
The house is generated by the Python files in `source/`:
- **To change the design:** edit the source, run `python3 export_glb.py P2 house_P2.glb`, and re-import.
- **Where things live:**
  - `plans.py`: rooms in metres
  - `furnish.py`: every furniture item, in metres
  - `hero3d.py`: what each piece looks like

## 8. The character rig (site: hero wave, later: routines)
`rig_character.py` rigs `character_abraham` and exports `public/house3d/character.glb` (also saves `character_abraham.blend`):

```bash
blender -b house3d/house_P2.blend -P house3d/rig_character.py -- public/house3d/character.glb
```

- Same mesh, same spot, same colours: it is built by `source/character.py` and split into rigid pieces, one per bone (thighs, shins, spine, head, arms, forearms, root). Each joint sits on the pivot the source rotates that piece around.
- The clips use the source's own pose angles (`character.POSES`): **idle** (stand, breathing, a glance aside), **wave**, **walk** (half-way to the designed run), **sit**.
- The script checks the rigged "wave" against the house's `character_abraham` and stops if they differ by more than a couple of millimetres (the bevel is welded per piece, so it differs very slightly).
- The site hides the house's static copy and shows the rigged one. The pet (`lab_pet_Pet`) is animated in code (`src/house3d/life.ts`): its body and eyes hop; the bed stays put.
- After changing the character or its clips, re-run the script, then the hero still: `node scripts/render-house3d-poster.mjs`.

## 9. Where he stands and walks
- **His mark** is `PERSON_AT` in `source/hero3d.py` (P2: plan (5.6, 5.2), moved there 2026-11-21 at Abraham's request so the HeroCamera sees him whole). Changing it means rebuilding the chain: `export_glb.py`, then setup → lighting → finish (save `house_P2.blend`), `export_web.py`, `rig_character.py`, `walks.py`, and the hero still.
- **Walks:** `walks.py` writes `public/house3d/walks.json`:

```bash
blender -b house3d/house_P2.blend -P house3d/walks.py -- public/house3d/walks.json
```

  Walls and doors come from the plan, furniture from the finished scene (rays from head height), so the paths go round whatever is there. The spots (records, turntable, sofa, pet, PC, books, garden tree) are listed at the top of the script, with what he does there. Add `--map out.png` for a picture of the walkable floor and the paths.
- The site (`src/house3d/life.ts`) walks him out from his mark every so often, and he always comes back to it. With reduced motion he stays on his mark.
