# design/ — reference for building the portfolio

Start here: `portfolio-handoff.md` (full brief, decisions, stack, milestones).

- `reference/` — the current screens as plain HTML (open in a browser). `0-build-spec.html` is the one-page spec.
  `1-home-v3.html` is the final visual direction. Files 2–5 show structure and behaviour only; restyle them to match Home v3.
- `tokens.json` — colours, type scale, layout, and the house plan/zoom numbers.
- `assets/house/` — 2D reference renders of the house (arrival / studio visited / all lit), `anchors.json` hotspot positions (% of image), and the Python generator that drew them. The real house will be a 3D scene; these are the look and the layout to match. The lit render doubles as the hero poster until the 3D poster exists.
- `assets/lab/` — screenshots for the lab projects (check before publishing internal names).

Placeholders in [brackets] are for the owner to fill. Never invent metrics.
